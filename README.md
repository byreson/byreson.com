# RESON

The first complete version of [byreson.com](https://byreson.com/) — Rijan Pradhan's personal corner of the internet for work, ideas, stories, interests, and whatever comes next.

## The site

RESON is a static, single-page personal website with sections for:

- Work
- Writing
- Now
- About

The visual direction is dark, minimal, and editorial. The site uses a warm near-black palette, strong responsive typography, generous whitespace, subtle motion, and a single lime accent colour.

## Technology

The site is built with only:

- HTML
- CSS
- Vanilla JavaScript

There are no frameworks, dependencies, package installs, or build steps.

## Run locally

Open `index.html` directly in a browser. A local static server can also be used, but it is not required.

## Files

- `index.html` — semantic page structure, content, navigation, and metadata
- `style.css` — responsive layout, visual design, focus states, and motion
- `script.js` — mobile navigation, entrance reveals, active navigation, and scroll progress

## Accessibility and behaviour

- Semantic landmarks and heading structure
- Keyboard-visible focus states and a skip link
- Accessible mobile menu state
- Responsive layouts for phone, tablet, and desktop
- Reduced-motion support
- Progressive enhancement so core content remains available without JavaScript

## Publishing

This repository is ready to be served as static files. No deployment or GitHub push is performed as part of this version.
