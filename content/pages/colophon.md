---

RESON is built with semantic HTML, modern CSS, vanilla JavaScript, and a small Python standard-library compiler. There is no frontend framework, package manager, database, analytics service, or client-side router.

Writing and project case studies live in portable Markdown. Now and personal records use JSON. One build turns those sources into static routes, metadata, topic connections, RSS, a sitemap, and a lightweight search index.

Inter Variable carries the interface. Newsreader Variable is reserved for long-form reading. Both are self-hosted as licensed WOFF2 files, and the browser downloads Newsreader only when an article needs it.

GitHub preserves the source and its history. Cloudflare Pages delivers the generated static site.

The site is designed around progressive enhancement, keyboard access, readable type, one warm light editorial identity, and useful HTML before JavaScript runs.
